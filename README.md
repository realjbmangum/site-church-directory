# Church Directory

A directory website helping people find local churches in their area. Search by location, denomination, service times, and more.

## Features

- Browse churches by denomination
- Search by location
- Individual church profiles with service times, contact info, and directions
- Mobile-friendly responsive design

## Tech Stack

- Astro (static site generation)
- Tailwind CSS
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321)

## Project Structure

```
src/
├── components/     # Reusable UI components
├── data/          # Church data (JSON)
├── layouts/       # Page layouts
├── pages/         # Route pages
└── styles/        # Global styles
```
